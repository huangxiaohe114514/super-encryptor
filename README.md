# 🔐 超级加密工具

一款基于 **5 层加密算法** 的文件加密解密桌面应用，加密后文件以乱码形式存储，有效防止敏感信息泄露。

## ✨ 功能特性

- 📁 **选择文件加密** — 自动转为 `.lock` 后缀，原文件加密完成后删除
- 🔓 **智能解密** — 从 `.lock` 文件头读取原始文件名，完美还原扩展名
- 🔒 **5 层加密** — AES-256-CBC + XOR + Base64 + 凯撒位移 + 比特反转
- 🎲 **乱码保护** — 密文转换为经典乱码字符，文本编辑器打开也无法阅读
- 🔑 **密码派生** — 使用 PBKDF2-HMAC-SHA256 安全派生密钥
- 💀 **自动清理** — 加密完成后自动删除原始文件，不留痕迹
- 🌙 **现代暗色 UI** — 舒适的视觉体验

## 🛡️ 加密算法

| 层级 | 算法 | 说明 |
|------|------|------|
| 1 | **XOR 异或** | 用派生密钥逐字节异或混淆 |
| 2 | **AES-256-CBC** | 行业标准对称加密，256位密钥 + 随机 IV |
| 3 | **Base64 编码** | 数据编码转换 |
| 4 | **凯撒位移** | 每个字节偏移 +7 |
| 5 | **比特反转** | 每个字节的 8 个二进制位反转 |

## 📦 安装运行

### 环境要求

- Python 3.8+
- Windows 10/11

### 安装依赖

```bash
pip install pyqt6 pycryptodome
```

### 启动应用

```bash
python super_encryptor.py
```

## 📖 使用方法

1. 点击 **「选择文件」** 选择要加密或解密的文件
2. 输入密码（不少于 4 位）
3. 点击 **「加密文件」** 或 **「解密文件」**
4. 加密完成后原文件自动删除，解密后文件名和扩展名完整还原

## 📄 .lock 文件格式

```
[4字节: 原文件名长度(大端)] [原文件名 UTF-8] [16字节: salt] [乱码密文]
```

文件头明文存储原文件名，确保解密后扩展名完整保留，不依赖文件名规律推断。
