功能特性

简洁界面，强大加密，为隐私而生

📁

一键加密

选择文件即可加密，自动生成 .lock 密文文件，原文件自动销毁。

🔓

智能解密

从文件头读取原始文件名，解密后扩展名完整还原，不依赖文件名规律。

🔒

5 层加密

AES-256-CBC、XOR、Base64、凯撒位移、比特反转，层层叠加，坚不可摧。

🎲

乱码保护

密文转换为经典乱码字符，即使文件被意外打开也无法阅读内容。

🔑

密钥安全派生

使用 PBKDF2-HMAC-SHA256 从密码安全派生 AES 密钥，抗暴力破解。

💀

自动清理

加密完成后自动删除原始文件，不留任何痕迹，干净利落。

加密算法层

数据流经 5 层处理，每层都有独特的变换逻辑

层级算法说明
1XOR 异或 XOR Cipher 用派生密钥逐字节异或，打乱原始字节分布
2AES-256-CBC AES Industry Standard 256 位密钥 + 随机 IV，行业标准对称加密
3Base64 编码 Base64 将二进制数据转为可打印字符，增加一层编码屏障
4凯撒位移 Caesar +7 每个字节偏移 +7，古典密码的现代应用
5比特反转 Bit Reversal 每个字节的 8 个二进制位完全反转，彻底打乱结构

.lock 文件格式

密文文件结构清晰，确保解密时能完整还原原始文件

[4 bytes] // 原文件名长度（大端序）
[N bytes] // 原文件名（UTF-8 编码）
[16 bytes] // salt（PBKDF2 派生密钥用）
[...bytes] // 乱码密文（5 层加密结果）

安装与运行

两条命令，即刻开始加密

1

克隆仓库

从 GitHub 下载项目代码

git clone https://github.com/huangxiaohe114514/super-encryptor.git
2

安装依赖

需要 Python 3.8+，安装 PyQt6 和 pycryptodome

pip install pyqt6 pycryptodome
3

启动应用

运行主程序，打开图形界面

python super_encryptor.py
